# maderas (retired)

The Apache configuration and scripts for maderas, the Linode that served BeeAtlas until 2026-10-23. Nothing here is deployed any more: production is the Fly app ([ADR 0042](../../docs/adr/0042-beeatlas-moves-to-fly-as-one-stateful-machine.md)). The files stay because [`fly/Caddyfile`](../../fly/Caddyfile) was ported from `beeatlas.net.conf` and cites it rule by rule.
